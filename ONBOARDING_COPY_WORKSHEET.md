# Onboarding Copy Worksheet

Every human-readable string in the onboarding flow, numbered, with space under each one for your wording.

How to use: write your replacement on the blank lines under an item. Leave it blank to keep what is there now. If it is easier, just reply in chat with the number and the new text, like "7: ...".

Every item shows where it lives: CATALOGUE (the authored copy file) or HARDCODED (a literal inside the UI Kotlin). When we build, everything moves into the catalogue.
