# PART 2 — THE QUESTIONS

questions across chapters. Every answer is stored twice: once in
the profile row on the device, and once as a sentence in the encrypted memory
brain.

Every question has these parts:

- **Prompt** — what GURU asks
- **Helper** — the smaller line underneath
- **Placeholder** — the grey example text inside the field
- **Review label** — the short label on the review page
- **Memory sentence** — how the answer is written into the brain. `{value}` is
  replaced with what the person wrote
- **In the always-on block** — whether the answer rides every single message
