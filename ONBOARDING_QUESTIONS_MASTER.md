# GURU ONBOARDING — MASTER QUESTION LIST

Every line here is a question. No scans, no notes, no stage directions.

Types: **short** one line · **long** free text · **tiles** multi-select tiles · **tabs** pick one word · **slider** left label to right label · **yesno** · **number**

All skippable except the first. Missing answers get picked up in conversation later.

## BUILD NOTES

- **140 questions.** Chapter one of the original list is gone: it was a scan, not a question.
- **Slider is the one type the code does not have yet.** Needs adding to `QuestionInput` with a left label and a right label, stored as a number in the same text column.
- **Spine before depth.** Identity, Voice, Life Shape, Rhythm and the Close give a working GURU and a tailored hello. Everything else is offered after the first win, not before it.
- **The first three answers must produce something personal back** before the length turns from a feature into a drop-off.
