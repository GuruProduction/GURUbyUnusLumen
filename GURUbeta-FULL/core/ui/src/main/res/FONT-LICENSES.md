# Bundled fonts

Every .ttf in `src/main/res/font/` is licensed under the
SIL Open Font License 1.1 (OFL) and comes from the Google Fonts catalogue.
Per-family licence texts: https://fonts.google.com (each family page, "OFL.txt").

Families bundled (36): Inter, Manrope, Outfit, Space Grotesk, Sora,
Urbanist, Figtree, Plus Jakarta Sans, DM Sans, Poppins, Nunito,
Montserrat, Fraunces, Lora, Playfair Display, Libre Caslon Text,
Crimson Pro, Merriweather, Bitter, Cormorant Garamond, Zilla Slab,
Newsreader, Bebas Neue, Anton, Archivo Black, Oswald, Righteous,
Unbounded, Syne, JetBrains Mono, IBM Plex Mono, Fira Code, Space Mono,
Caveat, Dancing Script, Pacifico.

The default app font (Rubik) is also OFL.
No proprietary fonts are committed to this repository.
